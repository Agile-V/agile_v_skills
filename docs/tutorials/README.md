# Agile V Tutorials

These practical guides apply the canonical lifecycle and `L0`-`L4` risk model to common adoption scenarios. Start with the guide closest to your task:

| Guide | Use it when |
|---|---|
| [Verified authentication](verified-authentication.md) | Changing authentication, authorization, identity, tokens, or sessions |
| [Independent agent verification](independent-agent-verification.md) | Separating synthesis from requirement-based verification |
| [AI run manifest](ai-run-manifest.md) | Recording material AI influence and revalidation triggers |
| [Regulated software adoption](regulated-software-adoption.md) | Introducing Agile V under an existing quality or regulatory system |

The normative sources are the [Canonical Lifecycle Contract](../agile-v-runtime/03_CANONICAL_LIFECYCLE_CONTRACT.md) and [Risk Classification](../agile-v-runtime/04_RISK_CLASSIFICATION.md). Tutorials illustrate those contracts; they do not replace organizational procedures, legal advice, or approval authority.

Related reading: [Comparisons](../COMPARISONS.md) and [Showcase submissions](../SHOWCASE.md).
