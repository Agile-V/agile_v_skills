# Public Standards Source Register

> **Status:** Informational; public-scope source register
> **Checked:** 2026-07-30
> **Use:** Verify the current edition, amendments, adoption status, and applicable text before use.

## Boundaries

This register links public publisher, regulator, and framework pages. It does not reproduce licensed standards, interpret law, establish certification, or replace a competent legal, regulatory, safety, or conformity-assessment review. Standard text, national adoptions, contracts, and sector rules may impose additional requirements.
