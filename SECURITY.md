# Security Policy

## Supported Versions

Security updates are provided for the current `3.8.x` repository line. Older lines are not supported. Individual skills marked `metadata.status: draft` are preview contracts and require local review before operational use.

## Report a Vulnerability

Do not open a public issue or discussion for a suspected vulnerability.

Use [GitHub Security Advisories](https://github.com/Agile-V/agile_v_skills/security/advisories/new) to report privately. Include affected files and versions, impact, reproduction details, and suggested mitigation when available. Remove secrets, personal data, proprietary prompts, and exploit details not needed to assess the report.

Maintainers will acknowledge the report, assess scope, coordinate remediation and disclosure, and credit reporters who request attribution. Timelines depend on severity and available evidence; no fixed response or resolution time is guaranteed.

This policy supports vulnerability handling but does not constitute a certification, warranty, or claim of conformity.
